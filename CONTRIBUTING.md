# Contributing

Please open an issue or pull request with a bounded change and evidence. This is a research prototype; distinguish a source hypothesis, local fixture result, telemetry observation and in-game visual confirmation.

For native changes, identify the supported runtime, validate exact entry signatures and calling conventions, preserve original call arguments/results outside the owned session, and balance retained references/scopes. Do not add broad player identity changes or alter unrelated actors. Include fixture coverage where it verifies meaningful safety or behavior.

For reports include native/controller versions, vehicle model, gravity, relevant settings, steps and observed behavior. Redact personal paths, save identifiers and unrelated logs. Do not upload game executables, extracted assets, saves, credentials, external framework DLL/source files or private compatibility content.

If investigating another project's implementation, cite the exact source commit and independently validate findings. Keep license provenance explicit. No claimed compatibility with another native vehicle controller is established by this repository.
